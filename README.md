# 青堤供水站取样台

白班巡检员依照巡检表登记批次和瓶单，值班员用单台台式设备逐瓶吸样。质控员在设备断开后凭原工单号领取样本及回执，并按批次定标复算。

## 一班的工作

1. 选择已登记的定标，登记批次并固定换算口径。
2. 按巡检表顺序提交工单号和瓶号，保留每个工单的首次队位。
3. 推进队首。控制库先记录在办工单及设备命令，再向设备发令。
4. 设备开工并完成吸样，递增完成号，将完成号和原码写入唯一留样槽。
5. 采集端以本工单的实际完成号核对留样，换算后成对提交原样和回执。
6. 回包丢失时按原批次重开续办。终局未明时等待，已完成时沿用原结果，确认旧命令终结且未完成后才重发。
7. 档案提交成功后确认本瓶交付，再推进下一瓶。提交拒绝时保留在办和原样。
8. 断开设备，重开工作库，按原工单号领取并复算。

## Python 接口

使用 Python 3.11 标准库。`control.workbench.Workbench.open(path, device_path=..., readings=..., seed=..., automatic=True)` 打开工作库和独立设备库。`readings` 是录制的瓶号到原码映射，可在初始化设备时提供。`seed` 可提供初始留样 `(完成号, 原码)`。重开采集应使用同一个设备库，参数省略时沿用已有录制。`Workbench.open(path)` 可断源打开。工作台支持 `with`，退出时关闭打开的连接。

| 调用 | 输入和结果 |
| --- | --- |
| `register_batch(batch_id, profile_id)` | 固定已有定标，返回 `BatchBinding`。同参重投返回原绑定。 |
| `submit_orders(batch_id, items)` | `items` 为有序列表或元组，每项是 `(order_id, bottle_id)`。逐项返回 `OrderAdmission`，含原 `job` 及可用的原 `sample`。同参重投保留队位。 |
| `advance(batch_id)` | 发令或继续本批在办瓶单，单次至多签发一瓶。返回 `StepResult`。 |
| `resume(batch_id)` | 续办本批在办工单。无在办时返回本批最近已确认的成果，尚无成果时返回 `idle`。 |
| `retrieve(order_id)` | 返回固定的 `PublishedSample`，未签时返回 `None`。 |
| `recompute(order_id)` | 按已签工单的批次定标和留存原码重新计算，未签时返回 `None`。 |

批次号、工单号和瓶号以原字符串为键。空白或非文本标识、未知批次或定标以及同号异参以 `ValueError` 拒绝。一组瓶单中任一项不合格，整组接纳回滚。`install_calibration(profile)` 登记由 `measurement.profiles.build_profile` 构建的固定定标。相同版本与定义可重投，同版异定义拒绝。新定标可供之后登记的批次选择。重复初始化沿用已有数据及定标。

`StepResult` 的 `published` 状态携带本瓶成果。`pending` 表示动作等待终局或设备已被占用，`idle` 表示当前入口无工单可处理。`source_read_failed` 表示设备访问失败或当前留样缺失、失配，`invalid_reading` 表示原码不符合定标，`commit_failed` 表示样本和回执的事务被拒绝。`checkpoint_failed` 表示档案已签发、控制进度仍需补认。前三种采集失败保留本瓶占用，进度补认失败也保留在办记录。其他批次在此期间不能派发。

`automatic=False` 时，发令可停在排队状态，由 `workbench.device.tick()` 一步推进至开工或完成。封口允许已排队的命令结清，关闭撤销未开始的命令。已开工的动作在两种方式下都要结束才能报告终局。完成时可生成通知，录制也可经 `queue_notice` 投递迟到或重复通知。`on_notices(batch_id)` 在有通知时核查本批进度。设备只提供最新留样，质控历史原码由档案提供。

## 换算与手算样例

原码为定标闭区间内的整数。空值、布尔值、非整数和越界值均返回无效读数。系数接受整数、有理数字符串或 `Fraction`，读数以精确有理值和固定单位保存。例中 `ntu-v1` 的原码范围为 0 至 31，读数为 `3x/8 + 1/4` NTU。

| 工单 | 瓶号 | 完成号 | 原码 | 手算读数 |
| --- | --- | --- | --- | --- |
| A | bottle-A | 41 | 17 | 53/8 NTU |
| B | bottle-B | 42 | 23 | 71/8 NTU |

`examples/shift.json` 给出设备从旧留样 40/12 开始的录制及独立预期。演示使用临时工作目录，实际检查动作账、档案账和断源复算。

```sh
python3 -B check_project.py
python3 -B -m control.workbench demo
```

完整回归覆盖有序采集、固定定标、整次接单拒绝、已签重投、排队及开工中的重开、未开工撤销后重发、迟到通知、源读失配、SQLite 提交拒绝、提交后进度补认、离线领取和无效原码。
